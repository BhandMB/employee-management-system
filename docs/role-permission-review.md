# Role Permission Review

Review every employee-management action against the intended role matrix.

| Action | Admin | HR | Employee |
|---|---:|---:|---:|
| View own profile | Yes | Yes | Yes |
| View all employees | Yes | Yes | No |
| Create employee | Yes | Yes | No |
| Update employee | Yes | Yes | No |
| Delete employee | Yes | No | No |

When permissions change, update security rules, controller annotations, UI affordances, and regression tests together.
