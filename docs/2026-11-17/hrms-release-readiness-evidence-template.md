# HRMS Release Readiness Evidence Template

## Build and quality
Record commit identifier, build command, build result, test suites executed, and any skipped tests with reasons.

## Functional verification
Capture evidence for login, role permissions, employee create/update/search, validation, and error handling.

## Data and operations
Record migration review, backup status, configuration checks, health checks, and rollback owner.

## Sign-off
List known issues, severity, owner, mitigation, and release decision. Do not mark a check complete without a linked result or named reviewer.
