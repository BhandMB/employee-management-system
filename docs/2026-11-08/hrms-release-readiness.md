# HRMS Release Readiness Checklist

> Created: 2026-11-08

A release checklist covering clean builds, automated tests, database migrations, secrets, backups, health checks, logging, error handling, accessibility, and rollback. Require evidence and an owner for each gate; do not imply these checks have passed.

## Evidence standard

Record implementation details only after checking the source code. Record test results only after running the relevant tests. If a behavior is not yet verified, keep it listed as an open verification item.
