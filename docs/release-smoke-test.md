# Release Smoke Test

1. Start the application with the documented configuration.
2. Confirm the health endpoint responds successfully.
3. Log in with an enabled test account.
4. Verify role-based access to employee data.
5. Create or update one test record and confirm persistence.
6. Verify the dashboard loads without server errors.
7. Confirm the API documentation endpoint is reachable.
8. Record any failing step before release.
