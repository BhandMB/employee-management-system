# Accessibility Review — 2026-09-06

## UI checks

- [ ] Form fields have visible labels and useful validation messages.
- [ ] Keyboard users can reach every interactive control.
- [ ] Focus order follows the page structure.
- [ ] Buttons and links have descriptive text.
- [ ] Tables remain understandable when read row by row.

## Resilience checks

- [ ] Empty, loading, and error states are present.
- [ ] Date and status values are readable without relying on color alone.
- [ ] Layout remains usable at narrow viewport widths.

Capture any fixes in the issue or pull request that introduced them so accessibility improvements remain traceable.
